Atomicity: each field stores one scalar value per row. Each independently occurring incident, dispatch, GPS log, report, attachment, maintenance record, alert, ambulance location, notification, and audit record is stored in its own relation, not as a repeating list in a user row. Every relation has its own surrogate primary key.
